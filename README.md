# 🏦 bank_parser_ai

An AI-powered financial utility designed to extract, parse, and structure data from unstructured bank statements (PDFs and images) into actionable formats like JSON, CSV, or Excel.

---

## 🚀 Key Features
* **OCR Integration:** Seamlessly handles scanned documents and digital PDFs.
* **Intelligence:** Leverages LLMs to accurately identify transaction dates, merchants, amounts, and categories.
* **Data Validation:** Built-in checks to ensure extracted totals match statement balances.
* **Format Flexibility:** Export to standardized schemas for easy integration with accounting software.

## 🛠️ Tech Stack
* **Language:** Python
* **AI Models:** (e.g., OpenAI GPT-4o / Claude 3.5 Sonnet)
* **OCR:** (e.g., Tesseract / Azure Form Recognizer)

## 📋 Prerequisites
Before running the project, ensure you have:
* Python 3.9+
* An API Key for your chosen LLM provider.
